# lazygit 文書一覧

[リポジトリの概要](../README.md)

このリポジトリは個人設定の導入・表示の調整・保守を扱います。lazygit 本体の導入・更新・削除は [setup-notes の導入手順](https://github.com/ryo-aoki-pc/setup-notes/blob/main/docs/lazygit.md)にあります。

## 目的から選ぶ

| 目的 | 読む文書・節 |
| --- | --- |
| 初めて個人設定を入れる | [前提ツール](setup.md#前提ツール) → [導入方法](setup.md#導入方法) |
| Windows で設定を配置し、退避分に戻す | [導入方法の Windows の例](setup.md#導入方法) |
| 速度優先・見やすさ優先・内蔵表示を切り替える | [delta の設定手順](diff-renderers.md#設定手順) |
| Windows で delta の設定例を使う | [Windows で使う場合](diff-renderers.md#windows-で使う場合) |
| 差分表示を見比べる | [表示の比較](diff-renderers.md#表示の比較) |
| Excel の差分を表示する | [Excel の導入](excel-diff.md#導入) → [確認と操作](excel-diff.md#確認と操作) |
| 大きい Excel ブックを表示する | [大きいブックの表示](excel-diff.md#大きいブックの表示) |
| カスタマイズや上流追従の作業をする | [ブランチ構成](maintenance.md#ブランチ構成) → [このリポジトリの運用](maintenance.md#このリポジトリの運用) |
